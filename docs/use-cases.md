## 결과까지 이어가는 시작 순서

1. [전체 상품](../PRODUCTS.md)에서 필요한 결과에 맞는 상품을 선택합니다. 상품의 공식 안내에서 입력과 준비 사항을 확인하세요.
2. [공식 상품 목록](https://xboss.biz/service-products?utm_source=github&utm_medium=repository&utm_campaign=xboss_connect&utm_content=use_cases) 또는 상품 상세의 시작 링크로 이동합니다. 기존 계정이 있으면 로그인하고 처음이라면 무료로 시작할 수 있습니다.
3. [AI 연결 안내](ai-connect.md)에 따라 앱에서 XBOSS를 연결하고 필요한 기관 연결을 콘솔에서 완료합니다. 비밀번호와 인증서 비밀번호는 채팅에 입력하지 않습니다.
4. 현재 도구의 입력을 확인하고 요청한 업무를 실행합니다. 발행, 신고, 신청과 초안 저장의 실제 효과를 확인한 뒤 진행하세요.
5. 접수 또는 작업 번호가 반환되면 같은 작업의 상태와 결과를 확인합니다. 데이터 없음, 부분 완료와 처리 실패를 구분합니다.
