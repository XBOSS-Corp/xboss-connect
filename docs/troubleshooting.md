# 문제 해결

먼저 계정 없이 연결을 확인하고, 이어서 내 계정 연결을 확인하세요. 진단 명령은 상품 작업을 실행하지 않습니다.

```sh
node bin/xboss.mjs doctor --anonymous
node --env-file=.env bin/xboss.mjs doctor
```

| 상황 | 다음 행동 |
|---|---|
| `node` 명령을 찾지 못함 | Node.js 22 이상을 설치하고 새 터미널을 엽니다. |
| `.env`를 읽지 못함 | 다운로드한 폴더에서 실행하고 `.env.example`을 `.env`로 복사했는지 확인합니다. |
| `doctor`가 `public`으로 표시됨 | 공개 목록만 확인한 상태입니다. [키 설정](quickstart.md#2-내-계정-연결) 후 `node --env-file=.env bin/xboss.mjs doctor`로 확인하세요. |
| 입력 파일을 찾거나 읽을 수 없음 | 현재 폴더와 `--input` 경로를 확인하세요. `schema <상품 slug> --template`의 출력은 UTF-8 JSON 파일로 저장하고 실제 값을 채웁니다. |
| 인증 실패 | 콘솔에서 키의 상태를 확인하고 `.env`의 두 값을 다시 확인합니다. 키 원문을 이슈에 올리지 않습니다. |
| 환경을 사용할 수 없음 | 키가 사용할 수 있는 환경과 `XBOSS_ENV_SCOPE`를 맞춥니다. |
| 찾은 상품이 도구 목록에 없음 | `schema <상품 slug>`로 현재 목록을 확인합니다. 공개 조회에는 `--anonymous`를 붙입니다. 계속 없으면 상품의 API·MCP 지원 여부와 내 계정 연결을 확인하세요. 이름을 추측해서 호출하지 않습니다. |
| 기관 연결이 필요함 | 응답이 안내한 공식 콘솔 화면에서 해당 기관을 연결합니다. |
| 같은 기관의 연결을 하나 고르라고 함 | REST 제출은 사용할 연결의 식별자를 `--account-link-id LINK_ID`로 지정합니다. MCP는 현재 `schema`의 `account_link_id` 지원 여부와 안내를 따릅니다. |
| 실행 가능 범위를 넘음 | 응답의 다음 행동이나 콘솔의 현재 이용 상태를 확인합니다. 반복 호출로 해결하지 않습니다. |
| 작업이 오래 걸림 | 받은 작업 번호로 `status` 또는 `wait`를 사용합니다. 새 작업을 다시 제출하지 않습니다. |
| 쓰기 확인이 필요함 | 서버의 미리보기를 확인한 뒤 사용자 확인을 받아 같은 내용으로 진행합니다. |
| 처리 결과를 확인할 수 없음 | 기존 작업과 해당 기관의 처리 여부부터 확인합니다. 신고·발행·신청을 곧바로 다시 실행하지 않습니다. |

## 응답이 끊겨 작업 번호를 받지 못했을 때

새 요청을 자동 제출하지 않습니다. 최초 요청의 입력과 복구 키를 먼저 확인하세요.

- REST는 최초 제출의 `--idempotency-key`와 같은 본문을 사용해야 기존 작업을 이어받을 수 있습니다. 같은 키로 다른 본문을 보내지 않습니다.
- 인증한 MCP 호출은 현재 스키마가 `request_idempotency_key`를 지원하고 최초 호출에 보냈을 때만, 같은 값과 같은 도구 인수로 해당 요청을 복구합니다. 상품별 `idempotency_key`는 다른 필드입니다.
- 키를 보관하지 않았거나 처리 여부가 불명확하면 기존 작업과 기관 처리 상태부터 확인하고 [공식 서비스 문의](https://xboss.biz/service-inquiry)를 이용하세요. 신고·발행·신청을 바로 반복하지 않습니다.

## AI 앱에 도구가 보이지 않을 때

앱별 [공식 설정 안내](https://developer.xdata.kr/common-guide/mcp-native-clients)를 확인하세요. 다른 MCP 설정은 유지하고, 설정 변경 뒤에는 안내에 따라 앱을 다시 시작합니다.

CLI 연결 확인은 성공하지만 앱에서 도구가 보이지 않으면 앱의 설정 위치와 연결 방식을 확인합니다. 앱에 도구가 보여도 상품 실행에는 별도 기관 연결이 필요할 수 있습니다.

## 문의에 포함할 정보

사용한 명령의 종류, 오류 코드, 발생 시각, Node.js 버전과 운영체제를 알려주세요. API 키·인증서·고객 자료·실제 입력 파일은 공개 이슈에 올리지 않습니다. 계정별 확인이 필요한 내용은 [공식 서비스 문의](https://xboss.biz/service-inquiry)를 이용하세요.
