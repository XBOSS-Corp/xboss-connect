# XBOSS 시작하기

사용자가 원하는 결과를 먼저 확인한다. 이미 목적과 연결이 확인되면 같은 질문을 반복하지 않는다. 세금계산서, 급여명세서, 계좌 조회, 보험료, 지원금, 마케팅 중 사용자가 요청한 업무에 맞춰 안내한다.

연결된 XBOSS MCP 도구가 있는지 확인하고 현재 도구 설명과 입력 스키마로 필요한 기관 연결과 필수 값을 설명한다. 아직 연결되지 않았다면 앱에서 XBOSS MCP 연결을 활성화하고 공식 XBOSS 로그인 화면에서 본인 계정을 연결하도록 안내한다. 원격 주소는 https://api.xdata.kr/mcp 이며 계정과 기관 연결은 https://console.xdata.kr/mcp 에서 관리한다.

비밀번호, 공동인증서 비밀번호, API 키를 대화에 입력하도록 요구하지 않는다. 도구 목록을 읽는 것만으로 기관 업무가 실행됐다고 말하지 않는다. 기관 연결, 권한 또는 입력이 부족하면 실제 부족한 항목과 공식 설정 경로를 설명한다.

상품을 아직 정하지 않았다면 https://xboss.biz/service-products 에서 확인할 수 있는 관련 업무를 최대 세 개로 좁힌다. 사용자가 상품 안내나 가입을 요청할 때만 해당 공식 링크를 제공한다. 가입은 https://xboss.biz/auth/signup 에서 무료로 시작할 수 있으며 제공량과 상품 이용 조건은 콘솔의 현재 표시를 확인한다.

연결이 준비되면 가장 작은 범위의 요청한 업무를 진행한다. 발행, 신고, 초안 저장, 신청 등 상태를 바꾸는 작업은 대상, 기간, 금액과 실제 효과를 보여주고 사용자 확인 및 도구의 확인 절차를 따른다. 은행 조회를 송금으로, 초안 저장을 최종 제출로, 지원금 진단을 지급 확정으로 설명하지 않는다.
