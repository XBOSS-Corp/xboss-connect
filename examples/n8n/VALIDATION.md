# 검증 범위

- 환경: Ubuntu, Node.js 24.22.2, n8n 2.45.7.
- 5종 모두 새 n8n에 가져와 실제 엔진에서 실행 성공.
- 각 업무: 제출 1회 → 진행 상태 조회 2회 → 결과 수신 1회.
- 승인 누락·응답 유실·실패·조회 재개 등 로직 테스트 43개 통과.

엔진 실행에는 localhost 모의 API와 가상 입력을 사용했습니다. 첫 검증 후, 별도의 가상 Basic Auth 자격 증명을 n8n에 등록해 5종 모두 다시 실행했습니다. 인증을 확인하는 모의 API에서 모두 성공했으며, 검증 사본의 대기 시간만 줄였습니다. 실제 홈택스 발행·신고, 고객 계정의 이용 권한, 기관 연결 성공을 증명하는 결과는 아닙니다.

배포 JSON에는 API 키·계정 ID·실제 업무 결과가 없습니다. 실제 사용 전 HTTP 노드 3개에 본인의 Basic Auth를 연결하고 입력·이용 조건을 확인하세요. 공식 n8n 라이브러리 제출과 승인 여부는 별도입니다.
